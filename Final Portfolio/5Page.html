Mini Game

For this assingment we took the concepts that we learned from the self portrait and applied it into a game scenario. Here we have a playable character that moves using a function that uses the keyis' ' applicaiton. We also have a ball that can be placed wherever the user clicks their mouse. Additionally it includes the use of obstacles which have been programed at random speeds and the use of "if" and "if else" statements. And lastly we have a "You Escaped!" display upon succesfully escaping that functions by reading where the ball is and producing the title when it travels within certain boundries.
